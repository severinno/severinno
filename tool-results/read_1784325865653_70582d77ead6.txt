    24→  - `join { userId, role }` -> joins rooms `user:{userId}` + `role:{role}`, ack `{ ok: true }`
    25→  - `message:send { fromId, toId, content, bookingId? }` -> emits `message:new` (id+timestamp) + `notification:new` to `user:{toId}`
    26→  - `booking:update { bookingId, clientId, providerId, status }` -> emits `booking:updated` to both `user:{clientId}` and `user:{providerId}`
    27→  - `quote:update { quoteId, clientId, providerId, status }` -> emits `quote:updated` to both rooms
    28→  - `tracking:position { bookingId, clientId, lat, lng }` -> emits `tracking:position` to `user:{clientId}`
    29→  - `ping` -> ack `{ pong: true, t: Date.now() }`
    30→  - `disconnect` -> logs reason
    31→  - connection logs socket id; SIGTERM/SIGINT graceful shutdown (io.close + httpServer.close + safety timeout).
    32→- Ran `bun install` in the mini-service folder (installed socket.io@4.8.3 + lockfile).
    33→- Started service in background: `nohup bun run dev > service.log 2>&1 &`. Verified log shows `WebSocket server running on port 3003`. HTTP poll on `/?EIO=4&transport=polling` returned 200.
    34→- Installed `socket.io-client` in the main project (`bun add socket.io-client`).
    35→- Created `/home/z/my-project/src/hooks/use-realtime.ts` — singleton client hook:
    36→  - Uses `io("/?XTransformPort=3003")` with path "/" (default), transports websocket+polling, reconnection enabled.
    37→  - SSR guard (`typeof window === 'undefined'`), singleton via module-level `socketRef`.
