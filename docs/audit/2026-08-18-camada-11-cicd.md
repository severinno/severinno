## 🔍 Análise Detalhada

### F-001 ⚠️ P1 — CI principal com 13 jobs paralelos (potencial custo alto)

**Arquivo**: `.github/workflows/ci.yml`
**Evidência**: 13 jobs independentes: lint, typecheck, test-unit, test-integration, test-e2e, build, security-scan, barrel-lint, cache-warm-check, coverage, benchmark, mutation, a11y

**Impacto**:

- Cada push ao `main` ou `release` dispara 13 jobs simultâneos
- Job `test-e2e` usa Playwright com 3 browsers (Chromium, Firefox, WebKit)
- Job `mutation` roda 24 scripts de mutação
- **Custo estimado**: ~15-20 min de compute por push ao main

**Recomendação**:

- Adicionar `paths-ignore` para docs/CHANGELOG para evitar pipelines em docs-only changes
- Considerar `concurrency` groups para cancelar pipelines anteriores na mesma branch
- Cache do pnpm já está configurado ✅
